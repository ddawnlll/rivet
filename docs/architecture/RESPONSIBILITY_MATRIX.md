# Responsibility matrix

| Bileşen | Tek cümlelik soru | Authoritative olmadığı şey |
| --- | --- | --- |
| **Active Cognitive Controller (LLM)** | Mevcut cognitive view altında ne anlama geliyor; hangi hipotez/eylem/yorum en uygunu? | Persistent identity, verification authority veya hard-state truth sahibi değildir |
| **Cognitive View Compiler** | Bu goal/workspace için hangi hard-state, evidence, relations ve artifacts model cognition'ına girmeli? | Seçtiği içeriği doğru veya complete ilan etmez |
| **Project Induction / Relevance Frontier** | Unseen repository'nin hangi bölümleri şimdi inspect edilmeli; hangileri defer edilmeli? | Pre-defined language/framework ontology dayatmaz |
| **Rivet Harness Core** | Cognitive cycle, state/view lifecycle, execution orchestration, cancellation ve continuation nasıl ilerlemeli? | Semantic meaning veya verification truth üretmez; fakat lifecycle Rivet'e aittir |
| **Goal Compiler** | Kullanıcı isteğinin objective, constraints, non-goals ve acceptance obligations'ı nedir? | Belirsiz user intent'i keyfi tamamlayamaz |
| **Scheduler** | Hangi task runnable ve dependency/resource açısından safe? | Semantic truth üretmez |
| **Repository Census / Probe** | LLM-led induction için hangi ucuz, mekanik repository signals güvenilir biçimde üretilebilir? | Repository semantics veya relevance kararı vermez |
| **Capability Resolver** | İstenen capability için en uygun verified provider hangisi? | Goal seçmez |
| **Artifact→Task Compiler** | Raw output hangi typed observation/state delta/obligation'a karşılık geliyor? | Belirsiz causality'yi zorla çözmez |
| **Invocation Economy** | Bu model interaction mekanik olarak gereksiz mi; aynı semantic control daha ucuz biçimde korunabilir mi? | Semantic cognition’ı sırf maliyet için bastırmaz |
| **Noesis** | Ne var, ne biliyoruz, ne varsayıyoruz, ne bilmiyoruz, ne çelişiyor? | Action permission vermez |
| **ACCP** | Claim/action evidence ve authority açısından meşru mu? | Kodun gerçekten çalıştığını kanıtlamaz |
| **Praxis** | Dünya/implementation acceptance condition'ı gerçekten sağlıyor mu? | Yeni mimari hipotezi üretmek zorunda değildir |
| **Hephaestus** | Normal search tıkandıysa framing/strategy nasıl değişmeli? | Routine scheduler değildir |
| **Evidence Ledger** | Hangi gözlem/artefact/action nereden geldi? | Interpretation yapmaz |
