# Roadmap

## Rivet 0.1 — State Architecture Falsification Prototype

- evaluation harness: same model / same capabilities / same sandbox baseline;
- Noesis Hard State: minimal event log + materialized epistemic state;
- Noesis Soft Workspace: bounded session/task state;
- Cognitive View Compiler with raw-text vs hybrid ablation;
- hierarchical repository census + LLM relevance traversal;
- thin execution adapter using ordinary read/search/shell/patch primitives;
- V8 flagship scenarios + at least two alien-project controls + one greenfield slice;
- metrics: verified success, repeated error, repeated reads, inspected bytes/files, tokens, calls, wall-clock.

**Exit criterion:** dramatic score hedefi yok. State architecture en az bir task family'de measurable positive signal üretmeli: birkaç puan verified-success, aynı success altında meaningful compute reduction veya repeated-error rate'te belirgin düşüş.

## Rivet 0.2 — Promotion, Verification and Cognitive Economy

- soft→hard promotion transactions;
- revision-aware invalidation / stale / superseded / reopened semantics;
- Praxis bounded verification integration;
- ACCP evidence admission and action authority;
- semantic capability experiments with raw escape hatch;
- invocation economy only after E1–E6 signal;
- state repair and epistemic-ossification benchmark.

## Rivet 0.3 — Generalization, Reframing and Scale

- long-lived multi-session project campaigns;
- more languages/build systems without core semantic forks;
- Hephaestus cold-path frame revision;
- conflict-aware worktrees / concurrency;
- multi-agent independence experiments;
- provider degradation/refresh and model replacement;
- production-scale repository relevance evaluation;
- paper draft only if ablations survive.
