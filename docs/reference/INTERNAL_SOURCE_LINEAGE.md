# Internal Project Source Lineage

Rivet bu dokümanda sıfırdan uydurulmuş bir product değildir. Bu monograf, önceki agent architecture notes'taki üç çekirdek fikri korur:

- **Historical v0.1 lineage:** Harness Core / persistent control-plane idea; retained as execution infrastructure, no longer as the owner of semantic cognition.
- **Preserved:** Noesis + ACCP + Praxis + Hephaestus separation of responsibilities.
- **v0.2 revision:** “deterministic when possible, model when necessary” is superseded as a primary cognitive doctrine by “LLM-led semantics; mechanize only mechanically decidable subproblems; human when authoritative.”

Earlier project notes remain useful for discover → verify → cache, determinate/discoverable distinctions and Hephaestus cold-path recovery. v0.2 reorders them beneath the primary state thesis: Noesis Hard/Soft State, Cognitive View Compiler and LLM-led Adaptive Project Induction come first; capability abstraction, invocation economy and scheduler optimizations are secondary layers.
