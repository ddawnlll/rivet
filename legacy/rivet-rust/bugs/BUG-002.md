**Priority:** P0

## Symptom and evidence

[OBSERVATION] Before the patch, a scripted model targeting the revision shown in its Cognitive View failed with `SemanticViolation("Verification request is outside the current repository or state revision")`; receipt and exit code 101: [.rivet/audit/evidence/BUG-002-reproduction.txt](/C:/Users/dresden/Documents/rivet/.rivet/audit/evidence/BUG-002-reproduction.txt), [.rivet/audit/evidence/BUG-002-reproduction.exit.txt](/C:/Users/dresden/Documents/rivet/.rivet/audit/evidence/BUG-002-reproduction.exit.txt).

## Root cause and discriminating observation

[INFERENCE] The model saw revision R, invocation accounting advanced Hard State to R+1, and the verification path incorrectly required the request to target R+1.

[OBSERVATION] The regression backend constructs its request from `request.cognitive_view.hard_revision`; after the patch the request reaches verification and the focused test passes: [cognitive_cycle_test.rs:70](/C:/Users/dresden/Documents/rivet/crates/rivet-core/tests/cognitive_cycle_test.rs:70), [.rivet/audit/evidence/BUG-002-cognitive-cycle.txt](/C:/Users/dresden/Documents/rivet/.rivet/audit/evidence/BUG-002-cognitive-cycle.txt).

## Final diff summary

[OBSERVATION] `HarnessCore::step` now passes the view revision to `run_verification_at`. That validator accepts the request's exact view revision while allowing only the single invocation-accounting increment as the current revision; older and more advanced revisions remain rejected. No revision model or public API was changed.
