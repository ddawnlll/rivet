# BUG-006 — Praxis pipeline fail-closed execution

**Status:** IMPLEMENTED / FULL-GATE VERIFIED; REVIEW PROTOCOL-LIMITED  
**Priority:** P1

## Symptom and evidence

[OBSERVATION] `VerityPipeline::run` previously invoked ExecGate after G1-G4 without requiring all prior verdicts to be `Pass`.

[INFERENCE] A plan that failed an earlier safety gate could still execute a declared command.

## Root cause and discriminating observation

[OBSERVATION] The regression plan fails the forbidden-file security gate and contains a child command that would create a sentinel. The sentinel remains absent; the synthetic ExecGate result is `Hold` with `PRIOR_GATE_NOT_PASS`. Receipt: [.rivet/audit/evidence/BUG-006-v3-targeted.txt](/C:/Users/dresden/Documents/rivet/.rivet/audit/evidence/BUG-006-v3-targeted.txt).

## Final diff summary

[OBSERVATION] Praxis now runs ExecGate only when every preceding gate verdict is `Pass`. Otherwise it records a fail-closed `Hold` result and does not invoke a command. Individual gate logic and successful pipeline order were unchanged.
